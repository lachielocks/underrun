# UNDERRUN

A sci-fi shooter originally created for the 2018 [js13k](https://js13kgames.com/) competition.

**Play:** [underrun.lachiethurlow.com](https://underrun.lachiethurlow.com)

Repo: [github.com/lachielocks/underrun](https://github.com/lachielocks/underrun)

Open `index.html` locally, or use `index-debug.html` for unminified sources.
